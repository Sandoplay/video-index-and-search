# Статус розробки системи мультимодального аналізу відео

## Виконані роботи (станом на 15.02.2026)

### 1. Підготовка інфраструктури
- Створено структуру каталогів проєкту (`src/`, `data/temp/`).
- Сформовано `requirements.txt` з урахуванням специфіки моделі **Qwen3-VL-8B** та потреб у квантуванні (`bitsandbytes`, `accelerate`).
- Визначено моделі даних у `src/models.py` для стандартизації обміну інформацією між модулями.

### 2. Реалізація модулів
- **Media Processor (`src/media_processor.py`):**
    - Вилучення аудіо у форматі WAV (16kHz, mono) для Whisper.
    - Автоматична детекція сцен за допомогою FFmpeg (фільтр `select='gt(scene,0.3)'`).
    - Вилучення ключових кадрів із прив'язкою до часових міток (timestamps).
- **Audio Transcriber (`src/transcriber.py`):**
    - Інтеграція OpenAI Whisper для перетворення мовлення в текст.
- **Vision Analyzer (`src/vision_analyzer.py`):**
    - Інтеграція моделі **Qwen3-VL-8B-Instruct**.
    - Реалізовано механізм Prompt Engineering: поєднання візуального ряду з текстовим контекстом транскрипції.
    - Додано підтримку 4-bit квантування для оптимізації використання відеопам'яті (VRAM).

### 3. Оркестрація
- Створено головний скрипт `main.py`, який реалізує повний цикл обробки:
    1. Обробка медіа (FFmpeg).
    2. Транскрипція (Whisper).
    3. Очищення кешу GPU для звільнення пам'яті.
    4. Візуальний аналіз (Qwen3-VL).
    5. Експорт результатів у формат JSON.
